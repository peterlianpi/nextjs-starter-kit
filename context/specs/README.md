# Specs

One file per feature unit. Order by number (`NN-`).

## Files

- `00-build-plan.md` — overall build order and unit breakdown
- `NN-kebab-name.md` — individual unit specs

## Rules

- Each unit is a single feature (one feature unit at a time)
- Use `_template.md` as the starting point for new specs
- Update `../progress-tracker.md` when a unit starts / completes
- Do not invent behavior outside the active spec + `../project-overview.md`
